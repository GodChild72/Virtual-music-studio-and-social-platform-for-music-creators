# Contributing

Thanks for your interest! A few guidelines:

- File locations
  - Put images under assets/images/
  - Put audio under assets/audio/
- Code style
  - Keep HTML/CSS simple and self-contained.
- Proposed changes
  - Create a branch, push, and open a PR targeting `main`.
  - Describe the change and list manual testing steps.
- Issues
  - Open an issue for features (recording, collaboration, sharing) or bugs.

Maintainer will review PRs and merge or request changes.
